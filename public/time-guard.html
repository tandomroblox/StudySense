STUDYSENSE · BROWSER EXTENSION

Make screen time visible.

Time Guard tracks website usage in your browser, gives you daily and weekly reports, and can apply a short allowance followed by a cooldown to the sites you choose.

Download Time Guard ZIP ↗View extension source

For Chrome and Microsoft Edge on desktop. This is a manually installed extension, not a Chrome Web Store listing. The download contains the extension files only.

◷

15-minute allowance

Choose restricted websites. Their tracked time counts toward the allowance; when it runs out, those sites are blocked for a 35-minute cooldown.

▥

Useful reports

See tracked time today, the last seven days, most-used sites, recent daily history, and export your totals as CSV.

⌑

Local by design

History stays in your browser profile. Time Guard does not upload it to your StudySense account or database.

SETUP · ABOUT 2 MINUTES

Install Time Guard

  1. 1

    Download and extract

    Use the ZIP download above, then extract it. Open the extracted folder and make sure manifest.json is directly inside it.

  2. 2

    Open your browser's extensions page

    In Chrome, open chrome://extensions/. In Edge, open edge://extensions/.

  3. 3

    Load the extension

    Turn on Developer mode, select Load unpacked, and choose the extracted folder that contains manifest.json.

  4. 4

    Choose your settings

    Pin StudySense Time Guard if you like, open it from the toolbar, select restricted-site-only tracking or all-website hostname tracking, then save. Browser permissions are requested when needed.

PERMISSIONS & LIMITS

Your data, your choice.

Restricted-site-only mode requests access to the websites you list. The optional all-website mode asks for broader host permissions so it can report hostnames across sites. It records hostnames and time totals—not page text, page titles, search terms, form entries, or keystrokes.

Time is estimated from the active tab while the browser window is focused, so browser throttling or sleep can make totals imperfect. Time Guard cannot monitor native desktop apps, other browsers, or activity while it is paused or removed. It is a self-management aid, not tamper-proof parental control. Incognito monitoring is not enabled by default.
