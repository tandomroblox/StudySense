Tracking settings

Tracking starts automatically with common entertainment sites on first install. Restricted-only mode tracks the domains below; all-websites mode reports hostnames for all active websites. Time Guard uses the browser tab permission already granted at install, so it does not ask for site-by-site confirmation. It never collects page content, titles, search terms, or form data.

Time counts cumulatively across all domains on this list—not 15 minutes per site. At 15 minutes total, a break popup appears and these sites are blocked for 35 minutes. Subdomains are included. Use one domain per line.

Your local data

Usage history stays in this browser profile. It is not uploaded to StudySense. The extension keeps up to 90 days of daily site totals.

Time is estimated from the active browser tab while the browser window is focused. It can undercount when the browser delays background alarms. This extension cannot monitor native apps or other browsers and is not tamper-proof parental control. Incognito monitoring is not enabled by default.
